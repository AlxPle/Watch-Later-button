## Cross-context reliability in Firefox

Version 1.6.2 brings key stability enhancements specifically for Mozilla Firefox users, resolving edge cases where YouTube's native action dispatcher failed to receive events:

- **Isolated world security & `cloneInto`**: When dispatching the `yt-service-request` action across window contexts in Firefox, event payloads are now securely cloned via `cloneInto(detail, pageWindow)`. This ensures seamless compatibility with Firefox's strict Xray vision security wrapper.
- **Window constructor resolution**: Custom events now correctly inherit the window-level `CustomEvent` constructor from `document.defaultView`, preventing context mismatches in complex multi-frame and background tab environments.

## Feed card observer resilience

YouTube frequently experiments with DOM container hierarchies across home feeds, search results, and subscription channels:

- **Multi-target fallback**: The card mutation observer now gracefully falls back through `ytd-app`, `#contents`, `#primary`, `document.body`, and `document.documentElement`.
- **SPA navigation recovery**: Button injection across video cards now reliably detects dynamic Single-Page Application (SPA) view changes, ensuring thumbnails in sidebars and subscription feeds consistently display the Watch Later action button.

## Refined translations across 26 languages

- Updated description and interface strings across all 26 supported locales (including French, German, Spanish, Japanese, Ukrainian, and more).
- Clarified button tooltips and undo notifications for consistent terminology with YouTube's localized interfaces.
