## Custom button color with RGBA alpha transparency

Version 1.6.0 introduces one of the most requested features: full customization of the Watch Later button's appearance directly from the extension popup.

You can now personalize the button to match your YouTube theme or personal preference:

- **Full color palette**: Choose any RGB shade with the native browser color picker or type standard HEX and HEX8 values directly.
- **Alpha-channel opacity slider**: Adjust button transparency from 0% to 100% using a smooth range slider.
- **Interactive live preview**: See your color and transparency in real-time over an integrated checkerboard stage before heading back to YouTube.
- **One-click reset**: Easily return to the classic YouTube red `#e50914` at any time with a single click.

## Instant live sync across all YouTube tabs

Color changes apply immediately without needing to refresh your tabs:

- Moving the slider or picking a new shade updates all open YouTube tabs and video thumbnails on the fly.
- Hover states are automatically calculated to provide a smooth contrast darkening effect.
- The confirmed "Added" state remains an unmistakable clear green, ensuring visual feedback stays intuitive.

## Redesigned popup with dedicated Settings

The extension popup has been redesigned for a cleaner, modern look:

- **Dedicated Settings navigation**: A prominent "Settings" item right below the playlist shortcut takes you straight to customization options.
- **Cleaner layout**: Removed unnecessary status pills and clutter, giving full breathing room to extension actions.
- **Unified sub-page view**: Clean `Back` navigation smoothly replaces the main menu when configuring colors.

## Under-the-hood performance & storage optimization

- **Local-first reactive sync**: Slider dragging uses rate-limit-free local storage for silky-smooth 60 FPS live preview without hitting browser quota limits.
- **Debounced cloud sync**: Settings are preserved across browser restarts and synchronized with your Google profile when idle.
- **Onboarding refresh**: Updated Welcome and Update pages now include color personalization guidance in the step-by-step walkthrough.
